# Northstar Coffee — Responsive Landing Page

A one-page coffee shop landing page built with semantic HTML and responsive CSS.

## Run locally
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Resize the browser or use DevTools device emulation at 375px to check the mobile layout.

## Files
- `index.html` — page content and structure
- `style.css` — layout, typography, colours, and responsive breakpoints

## Notes
- No build tools or package installation are required.
- Images and Google Fonts load from external services, so an internet connection is needed.
- The coffee shop name, address, email, menu and prices are sample project content and can be edited.
- The page uses a CSS-only mobile navigation menu.
